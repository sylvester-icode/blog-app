# Welcome to Blog App

This is a **modern blogging platform** built with Next.js, featuring user authentication, blog post managemnet, and a clean, intuitive interface

## Features

- **Create and Manage Blogs** - Write and publist you thoughts.

- **User Profiles** - Personalies user pages

- **Authentication** - Secure login and registration.

- **Comments** - Engage with blog posts.
